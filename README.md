# Bank Marketing — Deposit Subscription Prediction

## 📌 О проекте

Проект посвящён анализу данных банковской маркетинговой кампании и прогнозированию вероятности того, что клиент откроет срочный депозит.

**Цель проекта:**  
- исследовать клиентские данные;
- определить основные факторы, связанные с открытием депозита;
- построить ML-модель для прогнозирования открытия депозита;
- сформировать практические рекомендации на основе результатов анализа.

## 🗂️ Датасет

Использован датасет **Bank Marketing** (`bank-full.csv`).

Целевая переменная:
- `y` — открыл ли клиент депозит (`yes` / `no`).

В процессе подготовки данных целевая переменная была преобразована в числовой формат:
- `yes` → `1`
- `no` → `0`

## 🔎 Этапы проекта

Проект построен по четырём этапам:

### 1. Data Understanding

- Загрузка и первичный просмотр датасета.
- Проверка размера и структуры данных.
- Анализ типов данных и описательной статистики.
- Проверка пропущенных значений.
- Удаление дубликатов.

### 2. Descriptive Analysis

Проведён анализ распределения основных характеристик клиентов:

- возраст;
- баланс;
- профессия;
- образование;
- семейное положение;
- наличие ипотечного и потребительского кредита;
- тип контакта;
- месяц контакта;
- предыдущий результат взаимодействия с банком.

Для анализа использовались histogram, countplot и boxplot.

### 3. Diagnostic Analysis

Исследована связь характеристик клиентов с открытием депозита.

Особое внимание уделено:

- возрасту;
- балансу;
- длительности телефонного разговора;
- количеству контактов;
- профессии;
- образованию;
- семейному положению;
- наличию жилищного кредита;
- типу контакта;
- месяцу контакта;
- предыдущему результату кампании (`poutcome`).

### 4. Predictive Analysis

Для прогнозирования открытия депозита использована **Logistic Regression**.

Подготовка модели:

1. Целевая переменная отделена от признаков.
2. Категориальные признаки преобразованы в числовой формат с помощью `pd.get_dummies()`.
3. Данные разделены на train/test в соотношении 80/20.
4. Обучена Logistic Regression с `max_iter=1000`.
5. Модель оценена с помощью Accuracy, Confusion Matrix и Classification Report.

## 📊 Результаты анализа

В ходе анализа были выявлены следующие закономерности:

- Клиенты с предыдущим успешным взаимодействием с банком (`poutcome = success`) имели наиболее высокую долю открытия депозита — **64.73%**.
- Для клиентов с `poutcome = unknown` показатель составлял **9.16%**.
- Студенты и пенсионеры демонстрировали более высокую долю открытия депозита среди профессиональных групп — **28.68%** и **22.79%** соответственно.
- Для клиентов с высшим образованием (`tertiary`) доля открытия депозита составляла **15.01%**, против **8.63%** для клиентов с начальным образованием.
- Клиенты без жилищного кредита чаще открывали депозит: **16.70%** против **7.70%** среди клиентов с жилищным кредитом.
- Длительность телефонного разговора была одним из наиболее заметных факторов: клиенты с более продолжительными разговорами чаще открывали депозит.
- В марте доля открытия депозита достигала **51.99%**, тогда как в мае — **6.72%**.

> Эти показатели отражают результаты анализа данного датасета и не являются причинно-следственными доказательствами.

## 🤖 Результаты ML-модели

Для прогнозирования использована Logistic Regression.

| Метрика | Результат |
|---|---:|
| Accuracy | **89.86%** |
| Precision — класс 1 | **65%** |
| Recall — класс 1 | **34%** |
| F1-score — класс 1 | **45%** |

### Confusion Matrix

```text
[[7751  201]
 [ 716  375]]
```

Модель хорошо распознаёт клиентов, которые **не открывают депозит**, однако значительно хуже выявляет потенциальных клиентов, которые действительно открывают депозит.

Это особенно важно учитывать при интерпретации Accuracy: высокий показатель общей точности связан в том числе с дисбалансом классов.

## 💡 Prescriptive Recommendations

На основе проведённого анализа сформированы следующие рекомендации:

1. **Приоритизировать клиентов с успешным предыдущим взаимодействием**
   - `poutcome = success` показывает наиболее высокую долю открытия депозита.

2. **Повышать качество коммуникации с клиентами**
   - Длительность разговора (`duration`) связана с вероятностью открытия депозита и может использоваться как один из ориентиров при анализе эффективности контактов.

3. **Использовать клиентскую сегментацию**
   - Анализ показал различия между профессиональными и социально-демографическими группами клиентов.
   - Отдельное внимание можно уделять сегментам с более высокой исторической долей открытия депозитов.

4. **Учитывать ограничения ML-модели**
   - Recall для класса `1` составляет **34%**, поэтому модель пропускает значительную часть клиентов, которые фактически открыли депозит.
   - Для дальнейшего улучшения модели стоит рассмотреть балансировку классов, подбор порога классификации и сравнение с другими алгоритмами.
